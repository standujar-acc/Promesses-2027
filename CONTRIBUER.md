# Contester ou corriger un chiffre

1. Ouvrez une *issue* en indiquant le candidat, la mesure (identifiant `candidat.mesure`, par exemple `le-pen.retraites`), la valeur contestée et la valeur proposée.
2. Joignez une source publique et vérifiable : rapport officiel, institut, texte du programme.
3. Les équipes de campagne peuvent répondre de la même façon. Leurs contestations sont publiées avec la réponse.

Une correction est acceptée si la source est vérifiable et si elle respecte la convention de chiffrage (Md€ par an, effet sur le solde public, année pleine à l'horizon 2030, euros de 2026, sans effets macroéconomiques de bouclage).

Les signalements faits dans l'app arrivent dans la même file de vérification.
